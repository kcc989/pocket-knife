# AGENTS.md

- Read [docs/2026-10-25-jeval-plan.md](docs/2026-10-25-jeval-plan.md) before you change the design or start a
  phase.
- Follow [SimpleDoc](https://github.com/osolmaz/SimpleDoc) for Markdown files: a doc tied to a date goes in
  `docs/` as `YYYY-MM-DD-lowercase-title.md` with `title`, `author` and `date` frontmatter.
- Write commit messages and pull request titles as Conventional Commits. Add `[skip ci]` to
  documentation-only commits.
- Do not put coding-agent branding, such as co-author lines or "generated with" notes, in code, docs,
  commits or pull requests.
